## 3. 사용 시 유의사항

- **키워드 밀도 차이:** 423개 동 중 **195개 동만 동별로 따로 쓴 서술**이 있습니다(`대표_아파트_단지` ≠ `-`). 나머지 228개 동은 상권 유형별 기본 문장이 들어가 있어 동 사이 차이가 작습니다.
- **같은 서술을 공유하는 동:** 한 생활권을 묶어 쓴 경우 여러 동이 같은 키워드를 가집니다(예: 대치1·2동의 대표 단지, 가락1·2·본동의 헬리오시티).
- **1인가구비율 · 청년인구비율의 분모:** 상권분석서비스 상주인구가 아니라 **SKT 총인구**입니다. 재건축 입주 등으로 상주인구 집계가 늦은 동(예: 둔촌1동)의 왜곡을 피하기 위해서입니다. `Clau_pjt` 모델의 `청년비율`(20·30대 상주인구 ÷ 상주인구)과는 정의가 다릅니다.
- **행정동 수:** 기대소비 모델 결과(425개 동)와 비교하면 **항동(구로구), 둔촌1동(강동구)** 2곳이 이 파일에 없습니다.
- **조인 키:** 다른 데이터와 결합할 때는 이름이 아니라 `행정동_코드`를 쓰세요. `신사동`처럼 같은 이름의 동이 다른 구에 있습니다(강남구·관악구).
